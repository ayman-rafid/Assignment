# Project101

Student grade calculator written in C++. The program reads student names, homework
results, and exam scores, then calculates final points.

## Final Grade Formula

- Using homework average:
  `Final = 0.4 * HomeworkAverage + 0.6 * Exam`
- Using homework median:
  `Final = 0.4 * HomeworkMedian + 0.6 * Exam`
